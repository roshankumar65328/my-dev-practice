CSS Specificity

Important pseudo-elements ::before -> Element ke content se pehle virtual content add karta hai. ::after -> Element ke content ke baad virtual content add karta hai. ::first-letter -> Text ke pehle letter ko style karta hai. ::first-line -> Text ki pehli line ko style karta hai. ::selection -> User ke select kiye text ko style karta hai. ::placeholder -> Input ke placeholder text ko style karta hai. Important pseudo-classes :hover -> Mouse element par aane par. :active -> Element ko click/press karte samay. :focus -> Input select ya focus hone par. :first-child -> Apne parent ka pehla child. :last-child -> Apne parent ka aakhri child. :nth-child(2) -> Parent ka doosra child. :checked -> Checked checkbox ya radio. :disabled -> Disabled form element
